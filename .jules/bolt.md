## 2024-05-20 - [Optimize GameValidator.gridToString]
**Learning:** High-frequency serialization in Sudoku core (like `gridToString`) using `StringBuilder.append(int)` incurs hidden costs: dynamic array resizing (16->34->70->142) and heavy `Integer.toString()` conversions. Given that a Sudoku grid is always exactly 9x9 (81 cells) and contains digits 0-9, this is a prime target for allocation-free character arithmetic.
**Action:** When serializing fixed-size grids containing single-digit integers, bypass `StringBuilder` and `Integer.toString()` entirely. Allocate an exact-size `char[]` once, map integers to characters using ASCII math `(char)(value + '0')`, and wrap it in `new String(chars)`. Ensure any early-exit/fast-fail conditions (like `isValidGrid`) happen *before* the array allocation to save memory.
