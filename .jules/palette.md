## Critical UX/Accessibility Learnings
## 2026-10-11 - Adding accessibility content description to Loading ProgressBar
**Learning:** Indeterminate ProgressBars used as loading spinners should have an explicit `contentDescription` set via XML or code to assure screen reader accessibility during loading periods.
**Action:** Apply `contentDescription` systematically to all Loading spinner `ProgressBar` instances.
